# 视觉与动效规范

> 最后更新：2026-09-14 · 风格定位：**Motion Graphic × 文字几何（Typographic Geometry）**
> 实现载体：`app/globals.css` 的 `:root` token + Motion 动效

## 一、风格定义

三个关键词，任何视觉决策都必须同时满足：

1. **几何化**：一切形状来自圆、方、线、弧。不用插画风、不用拟物、不用阴影堆叠。
2. **文字即图形**：标题、编号、标签本身就是版式元素。大字号、紧字距、中英混排做节奏。
3. **运动有物理感**：所有位移、缩放、形变都由弹簧驱动，不用线性缓动。有惯性、有回弹。

反面清单（**不要做**）：圆角气泡对话框、渐变彩虹按钮、emoji 当图标、
模糊大光斑背景、卡片阴影堆叠、无意义的视差滚动。

## 二、色彩

深色舞台 + 四色状态系统。**四色不是装饰，是 Skill 分身的身份标识**，
同色在不同页面必须指同一个分身。

|---|---|---|
| `--ink-950` | `#07080f` | 页面底色 |
| `--ink-900` | `#0b0d17` | 输入框、下沉区域 |
| `--ink-850` | `#10121f` | 卡片 |
| `--ink-800` | `#161927` | 悬浮态 |
| `--ink-700` | `#1f2333` | chip 底 |
| `--line` | `#262b3d` | 主描边 |
| `--line-soft` | `#1c2032` | 分隔线、网格 |

| 状态色 | 主 | 浅 | 语义 |
|---|---|---|---|
| blue | `#4d7cff` | `#93b0ff` | 答主 A 组（贱贱 / 陈章鱼）+ 视角型补充层 |
| violet | `#8b5cf6` | `#c0a4ff` | 答主 B 组（张佳玮）+ 拆解者 |
| green | `#2fbf8f` | `#86e5c4` | 答主 C 组（李松蔚）+ 实操派 |
| orange | `#ff8a4c` | `#ffbb92` | 答主 D 组（半佛仙人 / 大猛）+ 缺口 |

文字层级：`--text-100` 正文主色 → `--text-300` 次要 → `--text-500` 辅助 → `--text-700` 极弱（仅标签）。

**orange 是缺口的专用色。** 缺口组件必须用 orange 左边框 + 橙色渐变淡出，与分身卡在视觉上区分开。

## 三、字体

| 用途 | 字体 | 说明 |
|---|---|---|
| 中文与正文 | **Manrope** → `PingFang SC` → `Microsoft YaHei` | 几何无衬线，字面干净 |
| 数字、代码、标签 | **DM Mono** | 用于 eyebrow、编号、统计数字、URL |

规则：
- 大标题 `letter-spacing: -0.025em`（紧），eyebrow `0.22em`（极松）+ 全大写。
- 这种「紧—松」对比就是文字几何的核心手法。
- 数字统一用 DM Mono，让统计区看起来像仪表盘而不是正文。

## 四、栅格与间距

- 容器最大宽 `1240px`，左右 padding `24px`（移动端 `16px`）。
- 间距阶梯：`4 / 8 / 12 / 16 / 20 / 24 / 32 / 56`。
- 圆角：`8 / 14 / 22 / 30`，对应 sm / 默认 / lg / xl。
- 网格底纹：`56px` 方格，透明度极低（`opacity: 0.72` 叠加多层渐变后用径向遮罩淡出），
  只在页面上半部可见，制造「坐标纸」的工程感。

## 五、动效规范

> **2026-09-15 重构：动效从「散的参数」收敛为「一套 token」。**
> 重构前实测存在 16 种硬编码时长、4 条互不相同的 cubic-bezier、3 套独立 spring 参数
> （320/300/260 × 34/30/26）——同一类交互在不同页面手感不一致，这是"精致度不够"的主因。
> 现在**唯一来源是 `lib/motion/tokens.ts`（JS）+ `app/globals.css` 的 `:root`（CSS）**，两者必须成对维护。

### 5.1 时长阶梯（`DUR` / `--dur-*`）

| Token | ms | 用途 |
|---|---|---|
| `instant` | 90 | 状态色切换、按下反馈 |
| `fast` | 160 | 悬停、焦点、导航激活 |
| `base` | 240 | 常规过渡、文本切换（默认值） |
| `slow` | 400 | 面板展开、背景渐变 |
| `slower` | 680 | 页面入场、连线绘制 |
| `read` | 600 | 需要被读到的停顿后动作 |
| `cinematic` | 1200 | 首屏开场、品牌动效 |

**选择规则**：越靠近用户手指的动作越短。悬停不会用到 `slow` 以上，
首屏开场不会用 `base` 以下。

### 5.2 缓动曲线（`EASE` / `--ease-*`）

| Token | 曲线 | 语义 |
|---|---|---|
| `standard` | `cubic-bezier(0.32, 0.72, 0, 1)` | 默认，进出对称 |
| `out` | `cubic-bezier(0.16, 1, 0.3, 1)` | 入场、出现（默认给入场用） |
| `in` | `cubic-bezier(0.7, 0, 0.84, 0)` | 退场、消失 |
| `emphasis` | `cubic-bezier(0.34, 1.4, 0.64, 1)` | 需要"弹一下"的重点动作 |

**禁止新增第五条第 4 条以外的曲线。** 重构时清掉了三处 `cubic-bezier(0.22, 1, 0.36, 1)`
（它是 `ease-out` 的近似重复品，肉眼几乎无差，但让体系多了一份噪音）。

### 5.3 位移阶梯（`SHIFT` / `--shift-*`）

`sm: 6px`（微反馈）· `md: 14px`（常规入场）· `lg: 28px`（大幅揭示）

**禁止手写像素位移。** 位移量的意义在于可预期——用户看到 14px 就知道是"这一层进来了"。

### 5.4 弹簧参数（`SPRING`，唯一来源）

| Token | `[stiffness, damping]` | 用途 | 手感 |
|---|---|---|---|
| `light` | `[320, 32]` | 顶栏、抽屉、状态条 | 干脆利落，几乎不过冲 |
| `card` | `[260, 28]` | 卡片入场 | 有轻微过冲，有重量 |
| `gap` | `[180, 22]` | 缺口揭示、图形分离 | 软，带呼吸感 |
| `magnet` | `[150, 18]` | 磁吸、指针跟随 | 最松，跟手 |

> 原 `CARD_SPRING` / `GAP_SPRING` / `BAR_SPRING` / `MAGNET_SPRING` 保留为别名但已
> 标记 `@deprecated`（`BAR_SPRING`、`MAGNET_SPRING` 审计为 0 引用），新代码一律用 `SPRING.*`。

### 5.5 编排节奏

| Token | 值 | 用途 |
|---|---|---|
| `STAGGER` | `0.06` | 列表错峰间隔 |
| `GAP_PAUSE` | `0.4` | 缺口揭示前的停顿——**留白是节奏的一部分，不可省** |

### 5.6 预设组合

- `FADE_UP`：`opacity 0→1` + `y: SHIFT.sm → 0`，`DUR.base` / `EASE.out`。最常用的入场。
- `FADE`：纯透明度，`DUR.fast` / `EASE.standard`。用于不该有位移的场景（如文本替换）。

### 5.7 品牌标识动效

`components/ui/LogoMark.tsx` 把 logo 拆成两层独立驱动，而非整体缩放（整体缩放是装饰，
没有记忆点）。标识的构造自带叙事：黑色侧影 = 真人，蓝色侧影 = 分身，交叠处的挖空圆 =
重合处生成的回答。

| 状态 | 行为 |
|---|---|
| 静止 | 两层严丝合缝，与静态图标完全一致（不让品牌形象走样） |
| hover / focus | 分身向侧后方移 `x:7 y:-10 scale:1.045`，真人仅微退 `x:-7 y:3`，让「本体稳住、影子才有动作」成立。整块 `.brand` 同时 `scale(1.04)` |
| reduced-motion | 不渲染任何动画，直接给静态合成图（同样走矢量，不额外下载位图） |

- 位移量刻意压到图形宽度的约 4%，品牌标识的首要职责是稳定可辨认。
- **暖白底砖 `#F7F6F3` 不可抠成透明**：黑头 `#151517` 与站点底色 `#07080f` 亮度仅差约 3%，
  抠掉后黑头会直接融进背景。保留底砖同时让动态版与静态图标是同一块「品牌砖」。
- **图形走矢量，不用位图**：顶栏 logo 只有 32px，位图方案要为它下载并解码两张 785×695
  的 RGBA 图；inline `<path>` 是零请求、零解码，且任意尺寸都锐利。
  轮廓由 `scripts/build-logo-vector.py` 生成到 `lib/brand/logo-paths.ts`，
  与 `app/icon.svg` 同源同坐标。
- 焦点联动走 CSS `.brand:focus-within` 挂在真实可聚焦的链接上，
  **不给装饰性元素加 `tabindex`**（否则凭空多一个 Tab 停留点）。

> ⚠️ `build-logo-vector.py` 里有两个已实测确认的坑，改脚本前必读：
> potrace 本版绑定沿用 PBM 约定（**0 = 黑**），必须传 `~mask`，否则它会把背景
> 当图形追踪，每个 path 都带上一整圈画布矩形轮廓；且**不能**做 `mask[::-1]`，
> 否则 y 轴上下镜像。脚本内已有断言，出问题会直接报错而不是静默产出糊图。


### 5.8 必须遵守

1. `prefers-reduced-motion: reduce` 时，所有位移改为淡入，看山停止循环动画，logo 降级为静态图。
2. 动效只用于**表达状态变化**，不做无意义装饰。
3. 首屏动画总时长不超过 1.2 秒（`DUR.cinematic` 是上限）。
4. 不用 `transition: all`，显式声明属性。
5. **新增动效必须用 token，不得写裸数值。** 改 token 时 JS 与 CSS 两侧同步改。
6. 焦点联动优先用 CSS `:focus-within` 挂在真实可聚焦元素上，
   **不要给装饰性元素加 `tabindex`**——那会凭空多出一个 Tab 停留点。

## 七、页面节奏（首页）

```
[顶栏]  品牌 + 导航 + 登录
[首屏]  eyebrow(HUMAN MESH · 真人专家网络) → 大标题 → 说明 → 输入框 + 召集按钮
        ↑ 看山在此处，尺寸最大，随输入状态变化
[舞台]  看山主持 + 分身网格（错峰入场，各自带状态色条）
[缺口]  ★ 橙色缺口区，视觉上与前一块明显断开
[网格]  Human Mesh 关系图（圆环 + 节点）
[页脚]  作品名 + 来源声明
```

**关键**：每一块之间用大间距（56px+）和细分隔线断开，让页面像「分镜」而不是长文。
