## 四、技术凭证与额度

### 凭证现状

| 变量 | 用途 | 当前状态 |
|---|---|---|
| `ZHIHU_ACCESS_SECRET` | 开放平台全部业务接口 | **已配置**（本地 `.env.local`，40 字符） |
| `ZHIHU_OAUTH_APP_ID` | OAuth 登录 | 未配置（需赛事页面创建项目后领取） |
| `ZHIHU_OAUTH_APP_KEY` | OAuth 换 token | 未配置（同上） |
| `ZHIHU_OAUTH_REDIRECT_URI` | OAuth 回调 | 已规划，未登记 |

> OAuth 凭证的领取时机官方文档明确写为「仍需核实」，不编造提前领取入口。
> 结论：**Demo 不依赖 OAuth 也能完整跑通核心闭环**，OAuth 作为加分项在拿到凭证后再接入。
