# Zhihu CLI：让你的 Agent 读懂知乎，也更懂你

![Zhihu CLI](https://developer-cdn.zhihu.com/zhihu-cli/docs/zhihu-cli-overview.png)

Zhihu CLI 是知乎数据开放平台面向 AI Agent 提供的官方命令行工具。

把配套 Skill 交给 Agent，它就能搜索知乎和全网内容、查看知乎热榜、调用知乎直答、发现适合回答的问题、查看问题下的回答摘要，还能在获得 Access Secret 后读取你自己的创作、关注与收藏，查询开放 API 剩余额度，以及按需读取、检索和上传知识库。

你不需要记接口或处理鉴权。告诉 Agent 想完成什么，它会选择合适的能力，并保留原始内容链接。

复制下面文字发送给你的 AI：

```text
请下载安装 zhihu-cli skill 并完成初始化配置
https://developer-cdn.zhihu.com/zhihu-cli/releases/stable/skill/zhihu-cli-skill.zip
```

## 能力一览

| 能力 | 适合解决什么问题 |
|---|---|
| 搜索知乎 | 查找社区里的真实经验、不同观点和具体案例 |
| 搜索全网 | 补充新闻、官网及其他外部资料 |
| 知乎热榜 | 了解当下正在发生和被关注的议题 |
| 知乎直答 | 对目标清晰的问题快速获得综合答案 |
| 问题发现 | 根据你的画像或指定主题推荐适合回答的问题 |
| 问题回答摘要 | 查看一个问题下的回答摘要和原文链接 |
| 本人创作全文、评论与数据 | 分别查看本人全文、评论、账号统计或单篇统计 |
| 我的创作 | 回顾自己的回答、文章、视频、想法和问题 |
| 我的关注 | 理解长期关注的人与知识方向 |
| 我的收藏 | 从收藏夹和近期收藏中找回积累的资料 |
| 知识库 | 查看知识库、检索资料，或上传明确指定的单个文件 |
| 额度查询 | 查看全网搜、知乎搜索、热榜、知乎问题回答、用户数据、创作能力、直答、知识库和小工具的当日统一额度 |


你可以直接这样说：

- “先看知乎用户怎么评价，再找几篇官方资料交叉核对。”
- “看看今天知乎上大家在讨论什么，补充事件背景。”
- “根据我的画像推荐几个适合回答的问题。”
- “推荐几个关于 AI Agent 的问题，再看看其中一个问题下有哪些回答。”
- “从我的创作里找出关于 AI 搜索的内容，整理一条时间线。”
- “读取我这篇文章的全文。”
- “看看我这篇回答下有哪些评论。”
- “查看我的账号创作数据，再看看这篇文章的数据表现。”
- “看看我最近收藏了什么，总结近期最关注的三个主题。”
- “在我的知识库里检索退款规则，并列出对应原始资料。”
- “把这份 PDF 上传到默认知识库，显示上传进度。”
- “查看我今天各项开放 API 还剩多少额度。”

Zhihu CLI 负责获取真实数据和链接。整理成报告、表格或 PPT，则取决于你所使用的 Agent 还具备哪些能力。

各项能力的额度与共享关系见[额度说明](/console/docs?key=quota)，也可以直接让 Agent 查询剩余额度。


## 开始使用

### 1. 把 Skill 发给 Agent

复制下面文字发送给你的 AI Agent：

```text
请下载安装 zhihu-cli skill 并完成初始化配置
https://developer-cdn.zhihu.com/zhihu-cli/releases/stable/skill/zhihu-cli-skill.zip
```


### 2. 生成 Access Secret

打开知乎数据开放平台个人中心：

<https://developer.zhihu.com/profile>

使用知乎账号登录并生成 Access Secret。请只在与 Agent 的私密对话中发送，不要放进公开群聊、文档或代码仓库。

Agent 会通过标准输入把凭证交给 Zhihu CLI。验证成功后，凭证保存在 macOS Keychain、Windows Credential Manager 或 Linux 桌面的 Secret Service，不会写入 Skill 文件夹和普通配置文件。Linux 的 SSH、CI 或容器场景通常由宿主 Secret Store 通过进程级环境变量注入。

### 3. 完成验证

Agent 会检查安装状态、版本兼容性和凭证有效性，并发起一次最小内容请求。内容列表为空也不影响验证，只要开放平台正常返回成功状态即可。

完成后，直接用自然语言提出任务，不需要手动输入 CLI 命令。

## 数据与安全边界

1. **只查询当前凭证所属账号。** Zhihu CLI 不接受 OAuth Token、用户 ID 或其他代查参数。
2. **个人数据按需读取。** Agent 不应默认遍历全部关注和收藏。
3. **摘要不等于完整原文。** 需要准确理解时，应继续访问返回的原始链接。
4. **更新不会静默执行。** Agent 会先征得同意；更新服务也不会接收 Access Secret、查询内容或个人数据。
5. **知识库按需操作。** Agent 不应自动遍历全部知识库，也只会在你明确指定文件并授权后上传；上传进度写入诊断流，最终结果仍保持机器可读 JSON。

## Access Secret 与 OAuth

Zhihu CLI 使用 Access Secret，服务于“让自己的 Agent 使用自己的知乎数据”。

第三方 Web 应用如果需要集成知乎登录、代表其他授权用户访问数据，应单独接入知乎 OAuth，不应把 Access Secret 分发给应用用户。

## 常见问题

### 为什么新会话会先检查状态？

Skill、CLI 和云端版本可能变化。每个 Session 首次激活时检查一次，可以确认能力是否可用和兼容。网络失败只会显示“暂时无法确认”，不会误报为最新版。

### Agent 会自动升级吗？

不会。存在更新时，Agent 会先完成当前任务，再询问是否更新。

### 可以查询其他知乎用户的个人数据吗？

不可以。Zhihu CLI 只查询 Access Secret 所属账号。访问其他授权用户的数据属于第三方应用场景，需要接入知乎 OAuth。
